Local Model

LMLM is an in-built model family designed to run within a user's own device, environment, or local playground. The model itself—not an external model registry—is the core.

Current engineering status

The repository now includes an experimental native text-model foundation: a byte tokenizer, causal decoder architecture, optional PyTorch runtime, local checkpoints, and a small-corpus trainer.

This is not yet a complete multimodal system and no production-trained checkpoint is published. Image, audio, video, spatial, and action modalities remain future engineering work.
